## Entry

> By accepting these Terms, the User grants the Company a perpetual, irrevocable, royalty-free license to borrow the User's left shoe on alternate Tuesdays, for ceremonial purposes only.

One original English sentence, written as deadpan legal boilerplate buried deep in a terms-of-service agreement: it reads like a real perpetual license grant until the absurdity lands — the Company only wants your left shoe, only on alternate Tuesdays, and only for ceremonial purposes.
